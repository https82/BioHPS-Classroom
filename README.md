# 探知·BioHPS：电信模型直连参赛版

本独立分支保留原教学内容，学生答疑与导师备课直接调用中国电信星辰大模型 **TeleChat3-438B-A24B**。学生和导师使用独立访问码进入各自工作区，通过学情与任务相互辅助。

新增流程：学生网页提问与练习 → 导师按专题生成并审核七节备课 → 导出同内容PPT并发布任务 → 学生作答 → 新记录自动进入导师学情。文件交接保留为备用方式。

运行入口为app.py，Python建议3.12，依赖见requirements.txt。模型参数与五个独立工作区访问码放在部署平台后台Secrets中，字段见.streamlit/secrets.example.toml。真实密钥和数据库不提交Git仓库。

完整说明见[电信模型参赛版说明](电信模型参赛版说明.md)。398项程序检查通过，并已执行电信模型真实调用与师生任务回流验证；Git分支存在不代表公网新站已部署。

本版使用官方模型API，不宣称通过TeleAgent桌面客户端代理网页请求。预设身份用于竞赛体验，SQLite记录位于运行实例本地；正式试用需要持久数据库与学校账号体系。

以下为保留的旧版本历史说明，当前接入和访问方式以上文及参赛版说明为准。

## 旧版V10.8：桌面学习工作台与师生双端导航修复

**这是一份可运行的Streamlit完整源码项目，不是纯静态网页设计稿。** 基于V10.7修改界面和导航，没有清空旧有5,000条微型学习资源、117道练习题、孟德尔/减数分裂深度课程、科学史专题、实验、连续AI对话、SQLite记录和教师备课PPT导出。

## 新版针对哪些实际问题

1. **教师端消失、进入页面后回不去：** 左侧始终显示与当前身份匹配的导航，顶部始终有“教师端 / 返回学生端”按钮。返回学生端时优先恢复上一次选择的演示学生；即使侧栏收起，也可操作顶部切换按钮。
2. **电脑大屏只是大片课程正文：** 主页改为桌面数据工作台，包括日期日历、最近七天学习活动、继续学习、当前任务、学习进度、AI快捷入口。
3. **学习程度和分数在哪里：** 按真正记录的答题计算正确率、练习次数、待复习知识点；未答题显示“—”，不虚构成绩。本次学习时间按当前浏览器会话计算，不声称历史累计时长。
4. **教师不便于掌握学情：** 教师首页显示演示班级实际参与人数、学生问题、答题与需订正次数、主要问题、最近提问，并保留详细证据与生成PPT入口。
5. **以前的功能能否继续使用：** 课程学习、AI学习助手、章节练习、科学探究、学习档案、教师问题与任务、备课与PPT保留在原项目的功能函数中。

## Windows：从正在使用的V10.7快速升级（推荐）

1. 退出正在运行的Streamlit，进入你**当前正在使用**且具有`app.py`、`lab_experience.py`的项目根目录。先在PowerShell备份：

   ```powershell
   Copy-Item .\app.py .\app_V10_7_backup.py -Force
   ```

2. 解压 `BioHPS_V10_8_ThreeFilePatch.zip`，将以下**三个文件**放入当前项目根目录：
   - `app.py`（替换）
   - `dashboard_ui.py`（新增）
   - `dashboard_styles.css`（新增）

   **不要删除原有** `knowledge`、`demo_data`、`.streamlit/secrets.toml`；也不要重新生成或分享API密钥。

3. 在**当前目录**启动（不需要先`cd`到之前猜测的文件夹）：

   ```powershell
   & 'F:\ai2\BioHPS_V6_2\.venv\Scripts\python.exe' -m streamlit run app.py
   ```

   如果你之前的Python虚拟环境已经移动，请把命令中Python执行文件路径替换为当前真实路径。

4. 浏览器按 **Ctrl+Shift+R** 强制刷新，查看左侧导航和顶部“教师端”按钮。

## 直接使用完整项目包

解压 `BioHPS_V10_8_FullProject.zip` 后进入其中 `BioHPS_V10_8` 文件夹，再用上面命令启动。独立压缩包故意不包含 `secrets.toml` 和已有SQLite学习记录，因此AI真实联网仍需你在本机安全地复制已有配置。**已有V10.7已连接的用户优先使用三文件补丁**，避免遗漏本地配置。

## 建议用电脑依次验收

- 学生A首页：日期、本次学习时间、练习次数、正确率、七天动态、课程卡、任务和快捷入口是否完整显示；点击课程和“返回首页”。
- 左侧依次进入 **课程学习 → AI学习助手 → 章节练习 → 科学探究 → 学习档案**；任何页面都可以继续切换左栏。
- 随便做一道章节练习，返回首页确认次数/正确率变化；进入学习档案核对错题。
- 点击**顶部“教师端”**，应进入班级学情；可在教师左栏进入“学生问题与任务”和“AI备课与PPT”。
- 点击顶部**“返回学生端”**，应回到学生首页。顶部切换不依赖左侧栏是否展开。
- 教师端的数字应来自实际学生记录；没有数据时应显示0或空状态，而不是演示假数据。

## 质量与使用边界

- 本版本的**所有新数据指标都来源于当前SQLite记录或当前浏览器会话**。不制造学习时长、考试成绩或班级人数。
- 当前5,000条是多类型微型学习资源，不等于已经通过教师逐项审核的5,000篇完整讲义。
- 已通过 **401项自动测试、55条离线页面分支、学生—教师演示业务流程**。
- 此运行环境未能安装Streamlit，因此未在真正的Streamlit浏览器会话中执行像素级验收。`design_preview` 下PNG是按相同CSS渲染的**静态布局预览，不是实际运行截图**。最终实际布局需要你在Windows上运行验收。
- 仅使用虚构演示学生身份和测试数据，尚不具备真实学校生产环境的账号权限与隐私保护体系。
